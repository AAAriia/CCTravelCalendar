## 1. 产品概述

### 1.1 背景与痛点

自由行用户在规划行程时，普遍面临以下问题：

- 用 Excel / 备忘录做行程，**调整日期和时间非常低效**：改一个时间要手动挪一整片内容；
- "想去的地方"（候选池）与"确定的行程"（时间表）混在一起，**缺乏候选 → 排期 → 取消回收的闭环**；
- 花费分散在各处，**缺乏按周的预算汇总视角**。

### 1.2 产品目标

提供一个**以周视图日程表为核心、右侧带日程库**的旅行计划工具，让用户可以：

1. 把候选日程（景点、餐厅、交通……）先录入日程库，不急于确定时间；
2. 通过**拖拽**把日程库中的卡片放到日程表上完成排期；
3. 排期后仍可**拖动改期、拖拽边缘调时长**，随时试算不同方案；
4. 一键**取消**日程，日程回到日程库等待重排，且预计日期自动回写为上次实际日期，方便下次参考。

### 1.3 目标用户与场景

| 用户 | 场景 |
| --- | --- |
| 自由行规划者 | 行前 1–4 周，收集了若干想去的地方，逐步排入周行程并反复调整 |
| 结伴出游的组织者 | 与同伴讨论后快速调整某天的安排，同步查看本周预估花费 |
| 周末短途出游者 | 快速安排 1–2 天的餐饮、景点、交通 |

### 1.4 名词解释

| 名词 | 定义 |
| --- | --- |
| 日程 | 一次可排期的旅行事项（如"西湖游船"），是本产品的核心对象 |
| 日程表 | 左侧主区域，按周展示的日历网格（横向 7 天 × 纵向时段） |
| 日程库 | 右侧栏，收纳所有已创建日程的"候选池"，支持按类型 / 地点 / 预计日期分组 |
| 已放置 / 未放置 | 日程的两种状态：已放置 = 已有确定的日期和时间；未放置 = 日期时间为空，等待排期 |
| 实际日期 | 日程当前被排到的日期（日程表上的日期） |
| 预计日期 | 用户预估该日程会安排到哪一天，**仅在详情弹窗中展示**；取消日程时自动回写为上次实际日期 |
| 取消 | 将已放置的日程从日程表移除、回到日程库未放置状态的操作（非删除） |

## 3. 功能需求

> 每个功能点包含：功能描述 / 交互细节 / 验收标准。字段展示位置的精确口径见《口径文档.md》。

### 3.1 周视图日程表

**3.1.1 周展示与导航**

- 默认展示本周（周一为一周开始）；顶部显示当前周范围"2026年8月24日 - 8月30日"。
- 点击 ◀ / ▀ 切换上/下一周；点击【今天】回到本周并滚动到当前时刻附近。
- 列头显示星期 + 日期（如"周三 8/26"）；今天的列头高亮标注。

**验收标准**

- [ ] 任意时刻点击【今天】都能回到本周且今日列有高亮；
- [ ] 切换周后，其他周的已放置日程正确显示；
- [ ] 顶栏周范围与表格列日期一致。

**3.1.2 时段网格**

- 纵向 00:00–24:00，30 分钟一刻度；页面初始自动滚动到 07:00 附近（旅行日程常见起始时段）。
- **凌晨折叠**：02:00–07:00 默认折叠为一条横带（点击展开）；展开/折叠状态记忆持久化；该时段有日程时自动展开；折叠带上可直接落放日程（落放后自动展开）。
- **日历选周**：顶栏周标题可点，弹出月历面板（翻月、今日与当前周高亮），选日即跳该周。
- 点击空白格（无卡片的区域）视同选中该时段，可在该格新建日程（v1 为加分项，见 8. 迭代）。

**验收标准**

- [ ] 时间轴刻度均匀、与卡片对齐无错位；
- [ ] 初始进入时可视区域在 07:00 附近而非 00:00。

**3.1.3 本周统计**

- 顶栏展示"本周已安排 N 项 · 预估花费 ¥min~max"（无波动时显示单值）。
- N = 本周（当前展示周）内已放置日程数；区间 = 各日程 [价格+下浮, 价格+上浮] 分别求和；未放置日程不计入。

**验收标准**

- [ ] 拖入 / 拖出（取消）日程后统计实时刷新；
- [ ] 有波动时显示 min~max 区间，负波动只影响下限；价格与波动均为空的日程按 [0,0] 计入 N 不增加金额。

### 3.2 日程卡片（位于日程表上）

**3.2.1 卡片展示**

- 卡片样式与市面主流日程表一致：左/顶部类型色条 + 事项名称 + 起止时间 + 地点 + 预估价格。
- 预计日期与备注**不在卡片上显示**，仅详情弹窗可见。
- 卡片高度按时长映射（30 分钟 = 1 格高度）；时间显示为"09:00 - 11:00"格式。
- 同一时段存在多个日程时，卡片左右并排显示，互不遮挡（允许时间重叠，不做强校验）。

**验收标准**

- [ ] 六类日程颜色可明显区分，与日程库分组颜色一致；
- [ ] 卡片高度随时长变化（1 小时 = 2 格高）；
- [ ] 重叠日程并排展示，鼠标悬浮可完整查看。

**3.2.2 拖动改期**

- 按住卡片主体拖动，可跨天列、跨时段移动；松手后按落点更新日期与开始时间。
- 拖动过程中显示半透明预览与目标格高亮；时间吸附 30 分钟刻度。
- 拖动后卡片上的时间立即更新；手动编辑详见 3.4。

**验收标准**

- [ ] 拖到另一天的任意时段，日期与时间同时更新；
- [ ] 松手位置吸附到 30 分钟整点刻度；
- [ ] 拖到 23:30 附近仍能正确放置（截至 24:00 不跨天）。

**3.2.3 拖拽边缘调时长**

- 鼠标移至卡片上/下边缘约 6px 内，光标变为上下调整样式；按住拖动即可调整。
- 拖上边缘 = 同时改变开始时间与时长；拖下边缘 = 只改时长；实时预览。
- 最小时长 30 分钟；底部越过 24:00 时自动截断到 24:00。

**验收标准**

- [ ] 上/下边缘调整的语义正确（上边缘改开始时间，下边缘改时长）；
- [ ] 时长不能小于 30 分钟；
- [ ] 结束时间不会超过当天 24:00。

**3.2.4 取消日程（× 按钮）**

- 卡片右上角常驻 × 按钮（悬浮时更明显）；点击后弹出轻量确认气泡"取消该日程？将移回日程库"。
- 确认后执行**取消**（非删除）：
  1. 卡片从日程表移除；
  2. 日程回到日程库，以对应类型颜色正常显示（不再置灰）；
  3. 日期、时间置空；
  4. **预计日期更新为该日程上次的实际日期**（即取消前所排的日期）。
- 取消操作仅针对已放置日程；未放置日程只存在于日程库中，无 × 按钮。

**验收标准**

- [ ] 取消后日程表上卡片消失、本周统计同步减少；
- [ ] 日程库中该日程恢复类型色，可再次拖拽放置；
- [ ] 打开详情可见预计日期 = 取消前的实际日期，日期/时间为空；
- [ ] 再次放置后又取消，预计日期更新为最新一次的实际日期。

**3.2.5 查看详情**

- 点击卡片主体（非 ×、非拖动）打开详情弹窗，见 3.4。

### 3.3 日程库（右侧栏）

**3.3.1 分组浏览**

- 顶部提供三种分组方式切换：**按类型 / 按地点 / 按预计日期**，默认按类型。
- 每个分组为可折叠区块：组头显示分组名 + 数量（如"景点 (3)"），点击展开/收起。
- 分组排序与空值处理口径见《口径文档.md》§6。
- **组内拖拽排序**：条目左侧 ⠿ 手柄拖动排序（当前分组内），插入线指示落点；顺序持久化，新建日程排组尾（§6.1a）。
- 库条目显示：类型色点、事项名称、地点、预估价格；已放置条目额外显示"已放置 8/26 09:00"标记。
- 预计日期与备注不在库条目上显示（仅"按预计日期"分组的组头显示日期）。

**验收标准**

- [ ] 三种分组切换后列表结构正确、数量正确；
- [ ] 所有已创建日程（无论已放置/未放置）都能在库中找到；
- [ ] 分组折叠状态在切换分组方式后重置为展开。

**3.3.2 拖拽放置**

- 未放置（类型色显示）的条目可拖动：拖动时显示跟随指针的拖拽幽灵，日程表上目标格高亮。
- 松手落表后：日程写入对应日期与开始时间（吸附 30 分钟），状态转为已放置。
- 已放置（灰色）条目**不可再次拖拽放置**（防止同一日程重复上表）；点击灰色条目可打开详情查看/编辑；如需改期请在日程表上直接拖动卡片。

**验收标准**

- [ ] 从库拖到表中，日期/时间按落点写入，卡片立即显示；
- [ ] 库中该条目变灰并显示"已放置 ××"标记；
- [ ] 灰色条目无法发起拖拽；
- [ ] 拖到日程表区域外松手 = 取消本次操作，无任何数据变化。

**3.3.3 新建日程**

- 库顶部【＋新建】按钮打开新建弹窗。
- 必填：事项名称、类型；选填：地点、预计日期、预估价格、备注；**日期/时间留空**（创建后进入日程库等待放置，也可在弹窗中直接填写日期时间，填写则直接上表）。
- 详见 3.4。

**验收标准**

- [ ] 新建后立即出现在日程库对应分组中；
- [ ] 未填日期新建 → 进入库为未放置状态；填了日期时间 → 直接出现在日程表上且库中置灰。

### 3.4 详情 / 新建弹窗

**3.4.1 字段与校验**

| 字段 | 控件 | 必填 | 校验规则 |
| --- | --- | --- | --- |
| 事项名称 | 文本输入 | ✅ | 非空，≤ 30 字 |
| 类型 | 六类单选（带颜色标识） | ✅ | 默认"景点" |
| 地点 | 文本输入 | ❌ | ≤ 30 字 |
| 日期 | 日期选择 | ❌ | 清空 = 移回日程库（未放置） |
| 开始时间 | 时间选择 | ❌ | 30 分钟对齐；有日期时必填 |
| 时长 | 下拉/步进（30 分钟步进） | ✅ | 30 分钟 – 24 小时，默认 60 分钟 |
| 预计日期 | 日期选择 | ❌ | 仅此弹窗可见 |
| 预估价格 | 数字输入 | ❌ | ≥ 0，保留两位小数 |
| 上浮幅度 / 下浮幅度 | 两个数字输入（均 ≥0） | ❌ | 可同时配置；区间 = [金额−下浮, 金额+上浮]，汇总与卡片按区间展示 |
| 备注 | 多行文本 | ❌ | ≤ 200 字，仅此弹窗可见 |

**3.4.2 状态联动（手动编辑）**

- 弹窗中填入日期 + 时间 → 保存后日程转为已放置并上表；
- 清空日期（或时间）→ 保存后日程回到未放置，日期时间置空（预计日期不回写，回写仅发生在"× 取消"路径）。

**3.4.3 操作**

- 【保存】：校验通过后落库并关闭弹窗；【取消】：放弃修改。
- 弹窗头部显示"查看/编辑日程"或"新建日程"。

**验收标准**

- [ ] 必填校验生效并给出提示；
- [ ] 手动改日期时间后，卡片位置与库中状态同步刷新；
- [ ] 详情中可见预计日期与备注（卡片和库上不可见）。

### 3.5 数据持久化

- 所有日程数据保存在浏览器 localStorage，刷新 / 关闭后重开不丢失。
- 提供示例数据一键重置入口（便于演示与试用）。

**验收标准**

- [ ] 任意增删改操作后刷新页面，数据保持一致。

## 4. 状态流转

```
                 ┌──────────────────────────────┐
                 │        （新建日程）              │
                 ▼                              │
           ┌───────────┐   拖入库条目到日程表       │    ┌───────────┐
           │  未放置    │ ─────────────────────▶ │    │  已放置    │
           │ (日期时间空)│                         │    │ (在日程表上) │
           └───────────┘ ◀───────────────────── ┴────┴───────────┘
                ▲          点卡片 × 取消：            │
                │          · 移回日程库               │ 拖动卡片/调时长
                │          · 日期时间置空              │ （保持已放置）
                │          · 预计日期=上次实际日期        │
                └────────────────────────────────────┘
```

- 未放置 → 已放置：拖入库条目；或详情弹窗填写日期+时间后保存。
- 已放置 → 已放置：表内拖动改期、边缘调时长、详情编辑（保持已放置）。
- 已放置 → 未放置：点 × 取消（预计日期回写）；或详情清空日期保存（预计日期不回写）。
- 无"删除"硬删除入口（v1 通过重置示例数据清空，删除功能见迭代规划）。

## 6. 边界与异常

| 场景 | 处理 |
| --- | --- |
| 同一时段放置多个日程 | 允许重叠，卡片并排显示 |
| 拖动越过 24:00 | 截断到当天 24:00，不跨天 |
| 时长缩到最小时长以下 | 钳制为 30 分钟 |
| 已放置条目再次拖拽 | 拦截，不发起拖拽（灰色态） |
| 拖拽在表外松手 | 视为放弃，无数据变化 |
| 新建必填项缺失 | 阻止保存并行内提示 |
| 浏览器不支持/禁用 localStorage | 降级为内存模式，刷新后数据还原为示例数据 |

## 8. v1 正式版新增功能（已实现）

### 8.1 删除与回收站

- 详情弹窗提供【删除】按钮：二次确认（明确提示"删除 ≠ 取消"）→ 软删除进入回收站（`deletedAt` 时间戳）。
- 回收站按删除时间倒序，展示原排期信息；支持【恢复】（回原位，含日期时间）与【彻底删除】（强确认后物理删除）。
- 回收站条目不参与日历、日程库、分组、统计。

**验收标准**：删除已放置日程后本周统计即时减一；恢复后回到原位置；彻底删除后不可恢复。

### 8.2 多行程方案

- 顶栏行程下拉切换 + 【管理】弹窗：新建 / 重命名 / 删除行程 / 打开。
- 删除行程 = 物理删除该行程全部日程（含回收站），确认框显示涉及数量；删除唯一行程时自动创建"我的行程"兜底。
- URL 深链 `#/plan/:planId`，切换行程同步路由，可收藏直达。

### 8.3 导入导出

- **导出**：全量 JSON（含全部行程与回收站，用于备份恢复）；当前行程 CSV（Excel 兼容，UTF-8 BOM）。
- **导入**：JSON，两种方式——合并（按 id 去重、同 id 整条更新）/ 覆盖（清空后替换）；先解析校验并输出报告（成功数、忽略数及原因），确认后原子写入，不产生半写状态。

### 8.4 移动端适配（<768px）

- 布局：顶栏紧凑化 + 横向 7 日日期条（今日蓝点、选中高亮）+ 单日时段列。
- 日程库改为底部抽屉（悬浮按钮唤起）。
- 交互口径：移动端**不做拖拽**——点选库条目弹出"放置面板"（选日期 + 30 分钟步进时间 + 时长）确认放置；卡片点按开详情改期；touch-action 与页面滚动互斥已处理。
- 弹窗全屏底部化，双列表单改单列。

### 8.5 勾选确认（v1.2）

- 每个日程可勾选，勾选 = 已确认（敲定的行程）；卡片与库条目均有 ✓ 控件，详情弹窗有开关。
- **自动勾选**：放置/移动/编辑上表后，若目标时段无其他日程重叠 → 自动勾选；有重叠不勾（可手动）。
- 取消回库 / 清空日期 → 自动取消勾选。确认状态不锁定编辑。

**验收标准**：放置到空时段自动出现绿 ✓；放入重叠时段无 ✓；× 取消后 ✓ 消失；手动勾选任意时刻可切换。

### 8.6 费用预算表（v1.2，v1.3 改为独立页面）

- 顶栏「预算表」入口 → **独立页面**（`#/plan/:id/budget`，非浮窗），页头提供返回与「导出 CSV（当前筛选）」。
- **一个行程对应一张预算表**：数据源绑定当前行程，切换行程自动切换、完全隔离。
- 与行程数据实时同步（同一数据源视图）。
- **两个表**：已确认行程 / 全部日程，各含条数、预估区间合计（min~max）、已付合计。
- 新增字段：费用类型（必须/可选，详情编辑）；**已付金额（仅预算表查看与行内编辑）**。
- 筛选：日程类型 / 费用类型 / 日期区间 / 地点（包含匹配），两表共用。

**验收标准**：行程表勾选变化 1 秒内反映到预算表；筛选组合生效；已付输入即时保存并更新合计。

### 8.7 复制行程（v1.2）

- 行程管理弹窗新增「复制」：生成"原名 副本"，完整复制日程（含勾选/费用类型/波动），**已付金额不复制**，复制后自动切换。

### 8.8 工程与质量

- 技术栈：Vue 3 + TypeScript + Vite + Pinia + Vue Router（hash）；零 UI 库、零拖拽库。
- 数据层 Repository 抽象（localStorage 实现 + schema 版本迁移），可平滑升级 IndexedDB / 后端。
- 质量门禁：Vitest 单测 + 组件集成测试（含 E1–E8 状态机全事件、取消回写、拖拽链路、移动端单日对齐等回归用例）、ESLint、vue-tsc 严格类型检查。
