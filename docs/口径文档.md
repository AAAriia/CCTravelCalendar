## 1. 名词与对象定义

| 名词 | 精确定义 |
| --- | --- |
| 日程（Schedule） | 一次可排期的旅行事项，全局唯一，由 `id` 标识；同一日程在日程表与日程库中是**同一份数据的两个视图** |
| 日程表 | 周视图日历网格：横向 7 列（周一~周日），纵向 48 行（00:00–24:00，30 分钟一行） |
| 日程库 | 右侧栏列表，展示**全部**日程（不区分状态），支持按类型 / 地点 / 预计日期分组 |
| 已放置（placed） | `date` 与 `startTime` 均非空的日程状态，卡片显示在日程表上 |
| 未放置（unplaced） | `date` 或 `startTime` 为空的日程状态，仅存在于日程库中 |
| 实际日期 | 字段 `date`，即日程当前被排定的日期 |
| 预计日期 | 字段 `expectedDate`，用户预估的意向日期；**仅在详情弹窗展示**；取消日程时被系统回写 |
| 取消 | 将已放置日程移出日程表、回到未放置的**业务操作**，数据不删除 |
| 时段（格） | 日程表 30 分钟一行的单元格，是拖拽吸附的最小时间单位 |

## 2. 字段口径表

| # | 字段 | 类型 | 必填 | 默认值 | 展示位置 | 编辑规则 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | id | string | 系统 | `sch_` + 时间戳 + 随机串 | 不展示 | 创建后不变 |
| 2 | title 事项名称 | string | ✅ | — | 卡片、库条目、详情 | 非空，≤30 字；新建必填 |
| 3 | type 类型 | enum | ✅ | `sight`（景点） | 卡片（颜色）、库条目（色点+文字）、详情 | 六选一，见 §2.1 |
| 4 | location 地点 | string | ❌ | 空 | 卡片、库条目、详情 | ≤30 字；为空时按"未填写"口径分组（§6.2） |
| 5 | date 日期（实际日期） | date(YYYY-MM-DD) | ❌ | 空（null） | 卡片（由所在列体现）、详情 | 为空 = 未放置；拖拽 / 取消 / 详情编辑均可变更 |
| 6 | startTime 开始时间 | time(HH:mm) | ❌ | 空（null） | 卡片、库条目（已放置标记内）、详情 | 仅 30 分钟对齐值；有 date 时必填（联动见 §3.3） |
| 7 | durationMin 时长 | int(分钟) | ✅ | 60 | 卡片（高度与结束时间体现）、详情 | ≥30，步进 30，≤1440；结束时间 ≤ 24:00 |
| 8 | expectedDate 预计日期 | date | ❌ | 空（null） | **仅详情弹窗** | 用户可改；取消日程时被系统回写（§5），回写可被用户再次覆盖 |
| 9 | price 预估价格 | number | ❌ | 空（null） | 卡片、库条目、详情 | ≥0，两位小数；空 = 区间下限按 0 计 |
| 9a | priceVariance 金额波动 | number | ❌ | 空（null） | 卡片（区间形式）、库条目（区间形式）、详情、统计 | 可正可负：**正数 = 可能上浮，负数 = 可能下浮**；空 = 无波动（区间退化为单值）。区间口径见 §8 |
| 10 | note 备注 | text | ❌ | 空 | **仅详情弹窗** | ≤200 字 |
| 11 | createdAt | timestamp | 系统 | 创建时刻 | 不展示 | 只读 |
| 12 | updatedAt | timestamp | 系统 | 更新时刻 | 不展示 | 任何字段变更时刷新 |

**状态字段说明**：不设独立 status 字段，状态为**派生值**——`date` 与 `startTime` 均非空 ⇒ 已放置，否则未放置（见 §3）。

## 3. 状态机口径

### 3.1 状态定义（派生规则）

```
已放置 ⇔ date ≠ null 且 startTime ≠ null
未放置 ⇔ date = null 或 startTime = null（两者在正常流中同时为空）
```

### 3.2 事件与字段副作用（全量枚举）

| # | 事件 | 前置状态 | 迁移 | 字段副作用 |
| --- | --- | --- | --- | --- |
| E1 | 新建日程（不填日期时间） | — | → 未放置 | 写入 title/type/可选字段；date=null、startTime=null、durationMin=60 |
| E2 | 新建日程（填了日期+时间） | — | → 已放置 | 同上，且写入 date、startTime |
| E3 | 库条目拖入日程表 | 未放置 | → 已放置 | `date` = 落点列日期；`startTime` = 落点格时间（30 分钟吸附，§4.2）；durationMin 保持不变 |
| E4 | 表内拖动卡片 | 已放置 | → 已放置 | `date`、`startTime` 按落点更新；其余不变 |
| E5 | 卡片边缘拖拽调时长 | 已放置 | → 已放置 | 上边缘：`startTime` 与 `durationMin` 联动（结束时刻不变）；下边缘：仅 `durationMin`；钳制 §4.4 |
| E6 | 点 × 取消（确认后） | 已放置 | → 未放置 | `expectedDate` ← 原 `date`（回写规则见 §5）；`date`=null；`startTime`=null；其余不变 |
| E7 | 详情编辑：填入/修改日期+时间 | 任意 | → 已放置 | 按表单值写入 date、startTime（时间自动向下对齐 30 分钟） |
| E8 | 详情编辑：清空日期或时间 | 已放置 | → 未放置 | `date`=null、`startTime`=null；**expectedDate 不回写**（区别于 E6） |

### 3.3 date 与 startTime 的一致性约束

- 两者必须同时有值或同时为空；任何路径不允许出现"有日期无时间"或"有时间无日期"的中间态持久化。
- 详情保存时若只填其一：按 E8 处理（两者均置空），并在界面上提示"日期与时间需同时填写"。

## 4. 拖拽与时间计算口径

### 4.1 刻度与映射

| 项 | 口径 |
| --- | --- |
| 刻度 | 30 分钟 = 1 格；格高固定像素值（原型为 44px），卡片高度 = durationMin / 30 × 格高 − 间距 |
| 周起始 | 周一为一周第一天；周范围 = [本周一, 本周日] |
| 日边界 | 一张卡片必须完整落在同一天内，结束时间 ≤ 当天 24:00，**不支持跨天** |

### 4.2 落点判定（拖入 / 拖动共用）

- 以**拖拽幽灵（drag ghost）的顶部边**所在的格为判定基准：
  - 所在列 = 目标日期；
  - 顶部所在格 = 目标开始时间。
- 指针位置与幽灵顶部的偏移在拖动开始时锁定，拖动过程保持，保证"抓哪里、落哪里"手感一致。

### 4.3 吸附规则

- 拖入 / 拖动 / 边缘缩放的结果时间一律吸附到 30 分钟整点刻度（如 09:14 → 09:00，09:16 → 09:30，四舍五入到最近刻度）。
- 详情弹窗手动输入非对齐时间时，保存前自动向下对齐到 30 分钟（如 09:20 → 09:00）。

### 4.4 时长钳制

| 规则 | 口径 |
| --- | --- |
| 最小时长 | 30 分钟，缩放低于下限时钳制为 30 |
| 日末截断 | 开始时间 + 时长 > 24:00 时，时长截断为 `1440 − 开始分钟数`；截断后若因上边缘拖动导致开始时间被推晚，则开始时间前移以满足最小时长 |
| 上边缘调整 | 结束时刻（= startTime + durationMin）保持不变，startTime 与 durationMin 联动重算 |

### 4.5 冲突（重叠）口径

- 不做冲突校验、不拦截：允许多个日程时间重叠。
- 展示：重叠卡片在同一列内**左右并排**均分宽度，层叠顺序按 startTime 升序、id 升序稳定排列。

### 4.6 拖拽中止口径

- 拖拽幽灵未进入日程表有效区域松手，或按 Esc：放弃操作，数据零变更。
- 已放置（灰色）的库条目不响应拖拽发起（指针按下即拦截）。

## 5. 取消与预计日期回写口径（核心规则）

### 5.1 回写规则

> 点 × 取消日程时：`expectedDate` ← 取消时刻该日程的 `date`（即"上次实际日期"）。

- "上次实际日期"定义：日程最近一次处于已放置状态时的 `date`（无论是拖入还是手动编辑产生的）。
- 多次"放置 → 取消"循环时，每次取消都覆盖回写为**最近一次**的实际日期。
- 回写发生在用户于确认气泡点击"确认取消"的瞬间；点"取消"关闭气泡则不回写、状态不变。

### 5.2 示例推演

| 步骤 | 操作 | date | startTime | expectedDate | 状态 |
| --- | --- | --- | --- | --- | --- |
| 0 | 新建"灵隐寺"，预计日期填 8/28 | null | null | 08-28 | 未放置 |
| 1 | 拖入 8/26 09:00 | 08-26 | 09:00 | 08-28 | 已放置 |
| 2 | 点 × 取消 | null | null | **08-26**（回写） | 未放置 |
| 3 | 再拖入 8/29 14:00 | 08-29 | 14:00 | 08-26 | 已放置 |
| 4 | 再点 × 取消 | null | null | **08-29**（覆盖回写） | 未放置 |

### 5.3 与 E8 的区别

| 路径 | expectedDate 是否回写 |
| --- | --- |
| 点 × 取消（E6） | ✅ 回写为上次实际日期 |
| 详情清空日期保存（E8） | ❌ 不回写，保持用户上次填写值 |

## 6. 日程库分组口径

### 6.1 通用规则

- 分组维度三选一：类型 / 地点 / 预计日期；切换后分组全部展开。
- 每组显示"组名 (条目数)"；组内条目按创建时间升序。
- 库始终包含**全部**日程（已放置 + 未放置）。

### 6.2 各维度分组细则

| 维度 | 组排序 | 组内容口径 |
| --- | --- | --- |
| 按类型（默认） | 固定顺序：交通 → 住宿 → 餐饮 → 景点 → 购物 → 娱乐 | 按 `type` 归组；六类**固定展示**（数量为 0 时灰显）以便拖拽时形成位置记忆 |
| 按地点 | 组名按拼音/字典序升序 | 按 `location` 精确字符串归组；为空的条目归入"未填写"组，排在最后 |
| 按预计日期 | 组名（日期）升序 | 按 `expectedDate` 归组；为空归入"未设定"组，排在最后；**组头显示日期，条目上仍不显示预计日期** |

### 6.3 库条目展示与置灰口径

| 状态 | 样式 | 可见字段 | 可拖拽 |
| --- | --- | --- | --- |
| 未放置 | 类型色点 + 正常文字色 | 色点、事项名称、地点、预估价格 | ✅ 可拖入日程表 |
| 已放置 | **整体置灰**（去饱和度 + 60% 透明度） | 上述字段 + "已放置 8/26 09:00"标记 | ❌ 拦截（点击可打开详情） |

> 置灰的含义：该日程已排在日程表上，防止重复放置；如需改期请在日程表上直接拖动卡片。

## 8. 统计口径

| 指标 | 定义 |
| --- | --- |
| 单条区间 | `min = price + min(v,0)`，`max = price + max(v,0)`（v = priceVariance，price 空按 0 计）；**下限不低于 0**。v>0 → [price, price+v]；v<0 → [price+v, price]；v 空 → [price, price] |
| 本周已安排 N 项 | 当前展示周 [周一, 周日] 内 `date` 落入该区间的日程条数 |
| 本周预估花费 | 上述日程的区间求和：**最小值 = Σ min，最大值 = Σ max**；无任何波动时 min=max，显示单值 |
| 展示格式 | `¥6,337~8,295`（min==max 时 `¥8,295`）；卡片/库条目对单条日程显示 `¥2,553~3,053` |
| 分组数量 (n) | 该组内日程条数（含已放置与未放置） |
| 计入/移出时机 | 任何导致 `date` 变化的操作（拖入/拖动/取消/编辑）后即时刷新 |

## 9. 持久化与初始化口径

| 项 | 口径 |
| --- | --- |
| 存储位置 | localStorage 单键存储全量数据（plans + schedules + lastPlanId），带 version 字段 |
| 写入时机 | 任何字段变更（E1–E8、删除/恢复/彻底删除、行程操作、导入）后立即全量写入 |
| 读取时机 | 应用挂载前读取并初始化（路由重定向依赖 lastPlanId）；无数据 / 解析失败 / 存储不可用时，加载内置示例数据（内存模式降级） |
| 重置 | "重置示例数据"操作恢复种子并回到本周 / 按类型分组，需二次确认 |
| ID 唯一性 | `sch_`/`plan_` + 时间戳36进制 + 随机串，重置/新建均不回收旧 ID |
| 坏数据防御 | 读取时逐条 normalize：非法字段回退默认值；date 与 startTime 只剩其一时连带置空（§3.3）；孤儿日程挂到第一个行程 |

## 10. 删除与回收站口径（正式版 v1 新增）

| 项 | 口径 |
| --- | --- |
| 软删除 | `deletedAt` 置为当前时间戳；卡片从日历消失、条目从日程库消失、不参与统计 |
| 删除 ≠ 取消 | 取消（E6）保留数据回库等待重排；删除进回收站。确认文案需明示二者区别 |
| 恢复 | `deletedAt` 置空；**保留原 date/startTime/expectedDate**，已放置的回到原排期位置 |
| 彻底删除 | 物理移除记录，不可恢复，需强确认 |
| 排序 | 回收站按 `deletedAt` 降序 |
| 事件隔离 | `deletedAt ≠ null` 的日程不响应 E3–E8 全部状态机事件 |

## 11. 多行程口径（正式版 v1 新增）

| 项 | 口径 |
| --- | --- |
| 行程（Plan） | 独立的日程集合；日程通过 `planId` 归属唯一行程 |
| 切换 | 顶栏下拉切换；当前行程持久化为 `lastPlanId`；URL `#/plan/:planId` 深链同步 |
| 视图隔离 | 日历 / 日程库 / 统计 / 回收站均只展示当前行程的数据 |
| 新建/重命名 | 名称 ≤30 字，空名回退默认（"未命名行程" / 保留原名） |
| 删除行程 | 物理删除该行程及其全部日程（含回收站），确认框显示数量；删除当前行程后自动切到首个剩余行程；无行程剩余时自动创建"我的行程" |

## 12. 导入导出口径（正式版 v1 新增）

| 项 | 口径 |
| --- | --- |
| JSON 导出 | 全量（全部行程 + 全部日程含回收站 + 版本号 + 导出时间），文件名 `行程板-备份-YYYY-MM-DD.json` |
| CSV 导出 | 仅当前行程；列：行程/事项/类型/日期/开始/结束/时长/地点/预计日期/价格/状态/备注；UTF-8 BOM，含转义 |
| JSON 导入·合并 | 行程按 id 去重新增；日程按 id 整条更新或新增；`lastPlanId` 失效时回退首行程 |
| JSON 导入·覆盖 | 清空现有全部数据后整体替换 |
| 校验与原子性 | 先解析校验输出报告（成功数 / 忽略项原因），确认后一次性写入；结构非法（缺 plans/schedules）整体拒绝，不留半写状态 |
| 字段防御 | 导入数据逐条 normalize（§9 坏数据防御同规则） |

## 13. 移动端交互口径（正式版 v1 新增，<768px）

| 项 | 口径 |
| --- | --- |
| 布局 | 顶栏紧凑 + 横向 7 日日期条（今日蓝点、选中高亮、默认选中今天）+ 单日时段列；日程库为底部抽屉 |

| 单日对齐 | 单日视图仅渲染选中日的日程（回归测试锁定：选中日的卡片集与该日数据一致） |
| 弹窗 | 全屏底部化；双列表单改单列 |
